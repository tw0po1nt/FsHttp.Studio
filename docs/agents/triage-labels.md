# Triage Labels

The skills use five canonical triage roles. This file maps those roles to the label strings in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                        |
| -------------------------- | -------------------- | ---------------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer must evaluate this issue            |
| `needs-info`               | `needs-info`         | Waiting for more information from the reporter |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent        |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation                  |
| `wontfix`                  | `wontfix`            | Will not be fixed                              |

When a skill names a role, use the applicable label string from this table. One example is "apply the AFK-ready triage label".

Edit the right-hand column to match the vocabulary that you use.
