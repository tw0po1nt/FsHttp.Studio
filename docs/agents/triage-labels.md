# Triage Labels

The skills use five triage roles. Each role name is also the label string in this repo's issue tracker:

- `needs-triage` — a maintainer must evaluate this issue
- `needs-info` — waiting for more information from the reporter
- `ready-for-agent` — fully specified, ready for an AFK agent
- `ready-for-human` — requires human implementation
- `wontfix` — will not be fixed

When a skill names a role, use the label string of the same name. One example is "apply the AFK-ready triage label", which means `ready-for-agent`.
